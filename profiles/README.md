# Profile versions

- `v1/` — the original portfolio design.
- `v2/` — the simpler black-and-blue CV-based portfolio design.
- Both profiles share the repository root `resources/` and `assets/` folders.

The repository root is the active deployment source.

```text
scripts\switch-portfolio.bat v1
scripts\switch-portfolio.bat v2
scripts\switch-portfolio.bat status
```
